# Prospectos y clientes — límite con Presupuestos

La Fase 1 conserva `Client` como el único contacto comercial. Un prospecto se
convierte en el mismo registro, por lo que sus presupuestos, eventos y actividad
no se copian ni se recrean.

No se añadió todavía un botón que cree un presupuesto desde la ficha. El flujo
actual de Presupuestos IA persiste un borrador vacío al iniciarse, así que no es
seguro presentarlo como «Preparar presupuesto» desde un prospecto. La siguiente
fase debe cambiar el arranque de Presupuestos IA para recopilar o confirmar datos
antes de persistir el borrador y aceptar un `clientId` preseleccionado.
